# Effigy — site

Assembleur de tokens vus de dessus pour Foundry VTT, dans l'esprit Warhammer 40K.

Cette branche contient le site web (une seule page, `index.html`), publié via GitHub Pages.
Le module Foundry VTT vit sur la branche `main`.

## Fonctionnement

- Bibliothèque de pièces PNG (corps, tête, épaulière, bras & armes, dos, accessoire, socle)
- Calques transformables : position, taille, rotation, miroir, teintes A/B/C
- Contour encré, usure, ombre portée, socles texturés avec bord de disposition
- Escouades et variantes, états (blessé, à terre, mort, nuit, invisible)
- Export WebP/PNG ou ZIP, sauvegarde locale et projet `.json`
